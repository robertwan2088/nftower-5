# NFT7 - 现代化 NFT 交易平台

## 项目介绍

NFT7 是一个现代化的 NFT 数字资产交易平台，结合了优秀的设计理念和先进的技术实现。项目参考了主流 NFT 平台（如 OpenSea、Rarible）的设计风格，同时融入了创新性的交互体验。

## 技术栈

- **HTML5**: 语义化标签，结构清晰
- **CSS3**: 现代化布局，渐变效果，动画过渡
- **JavaScript (ES6+)**: 交互逻辑，动态效果
- **Font Awesome**: 图标库
- **DiceBear**: 头像生成服务

## 项目结构

```
nft-7/

    │   ├── style.css       # 全局样式

    │   ├── market.js       # 市场交互
    │   └── utils.js        # 工具函数

```

## 使用方法

### 1. 直接打开
直接用浏览器打开 `index.html` 文件即可查看效果。

### 2. 本地服务器（推荐）
使用任何本地服务器运行项目，例如：

```bash
# 使用 Python
python -m http.server 8000

# 使用 Node.js (http-server)
npx http-server -p 8000

# 使用 PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

### 3. 在线部署
可以将项目部署到 GitHub Pages、Vercel、Netlify 等平台。

## 注意事项

- 部分图片使用了占位符，实际项目中需要替换为真实图片
- 头像使用了 DiceBear API，可以根据需要替换
- 数据为模拟数据，实际项目需要接入后端 API

## 开发建议

1. **图片优化**: 使用 WebP 格式，压缩图片大小
2. **代码分割**: 进一步拆分 CSS 和 JS 文件
3. **性能优化**: 实现虚拟滚动、图片懒加载等
4. **SEO 优化**: 添加 meta 标签、结构化数据
5. **测试**: 编写单元测试和集成测试
